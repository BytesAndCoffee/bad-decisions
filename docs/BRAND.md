# Small brand palette

Launch-facing assets use one deliberately small palette:

- **Primary orange:** `#b85618` — warm and mischievous, with 4.57:1 contrast
  against the button text cream.
- **Cream:** `#fffbf2`
- **Charcoal:** `#171511`
- **Secondary text:** `#706b62`
- **Dark orange text:** `#78341f`

The primary is intentionally darker than `#c86124`, which falls below 4.5:1
against the existing cream text. Reuse these values directly; no design-system
framework is needed.
