# Bad Decisions 2.0.0: the regret becomes structured

Bad Decisions 2.0 turns the original one-shot joke into a cleaner public
platform without making it appreciably more sensible.

## Highlights

- The versioned `/v2` API uses prompt and answer terminology throughout.
- Peer Pressure provides ephemeral multiplayer through `regret together`.
- CardDeck schema 2 preserves portable cards, licensing, and provenance.
- Consequences remains explicitly opt-in and gives operators local analytics.
- Immutable local releases support guarded rootless updates and rollback.
- Self-hosted and AWS-native deployments share the same engine and clients.

## Upgrade notes

- Existing API clients should follow [the 2.0 migration guide](../MIGRATING-2.0.md).
- Pack authors should rebuild archives with schema 2 and validate the result.
- Install the server with `pipx install bad-decisions` and Regret with
  `brew install bytesandcoffee/tap/regret` or
  `pipx install bad-decisions-client`.
- Pack content is not covered by the engine's MIT License. Preserve each pack's
  own license, attribution, and provenance when redistributing it.

## Safety and compatibility

The runtime remains immutable: public API requests cannot import or alter
packs. Archive parsing retains traversal, symlink, checksum, size, and
compression-ratio defenses. See the full [changelog](../../CHANGELOG.md) for
the version-by-version record.

Unfortunately, several of these were good decisions. Root-cause analysis is
ongoing.
