# Code of conduct

Be kind, specific, and constructive. Critique code and decisions rather than
people. Harassment, threats, discriminatory abuse, deliberate exposure of
private information, and sexualized attention directed at contributors are not
acceptable.

This project contains adult party-game content. That does not excuse hostile
behavior in project spaces, nor does it make every kind of content appropriate
for issues, reviews, or discussions.

Maintainers may edit or remove contributions and restrict participation to keep
the project safe and useful. Report conduct problems privately through the
maintainer contact described in [SECURITY.md](SECURITY.md). No response-time or
formal mediation guarantee is implied.
